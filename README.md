# ArbMusic

Тёмный музыкальный веб-плеер для компьютера и iPhone. На Android приложение можно собрать через Capacitor.

## Render

`render.yaml` настраивает веб-сервис Node.js и PostgreSQL. Веб-сервис раздаёт сайт и API аккаунтов на одном домене; база и сессии хранятся в PostgreSQL. При пуше в GitHub Render сможет автоматически собирать и публиковать изменения.

Для постоянной работы выставлены платные минимальные планы Render: веб-сервис Starter (сейчас $7/мес.) и PostgreSQL Basic-256mb (сейчас $6/мес.). Итого около $13/мес. до дополнительных расходов. Бесплатный веб-сервис засыпает после 15 минут тишины, а бесплатная база действует 30 дней.

Регистрация и вход используют номер телефона как логин и пароль. SMS-код не отправляется и номер не подтверждается: для подтверждения нужен SMS-провайдер.

## Запуск локально

Требуется Node.js 22 или новее.

```sh
npm install
npm run dev
```

Для локального API аккаунтов задай `DATABASE_URL` для PostgreSQL и выполни `npm start` после `npm run build`.

## Android APK

```sh
npm install
npm run android:add
npm run android:sync
npm run android:open
```

В Android Studio выбери **Build → Build Bundle(s) / APK(s) → Build APK(s)**. Для входа в аккаунт укажи URL опубликованного сайта в `auth-config.js` перед сборкой APK.

## Музыка

Демо-треки в проект не встроены. Можно добавить собственные аудиофайлы; они воспроизводятся в текущем браузере. Кнопка «Микс» перемешивает загруженные треки. Тексты песен добавляются пользователем и сохраняются в браузере.
