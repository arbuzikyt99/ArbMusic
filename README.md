# ArbMusic

Тёмный музыкальный веб-плеер для компьютера и iPhone. На Android приложение можно собрать через Capacitor.

## Render

`render.yaml` настраивает бесплатные веб-сервис Node.js и PostgreSQL. Веб-сервис раздаёт сайт и API аккаунтов на одном домене; база и сессии хранятся в PostgreSQL. При пуше в GitHub Render сможет автоматически собирать и публиковать изменения. Если база ещё не подключена, музыкальный сайт открывается, а API аккаунтов сообщает, что база не настроена.

Бесплатный веб-сервис Render засыпает после 15 минут тишины, а бесплатная база действует 30 дней. Для постоянной работы и базы без срока потребуется перейти на платные планы Render.

Регистрация отправляет пятизначный SMS-код через SMS.RU. Добавь `SMS_RU_API_ID` в переменные окружения Render; SMS.RU списывает плату за отправку. Код действует 10 минут, лимит — 5 попыток ввода, повторная отправка доступна раз в минуту, максимум 5 сообщений на номер в сутки. До подтверждения аккаунт не создаётся. Вход выполняется по номеру и паролю без повторного SMS.

## Запуск локально

Требуется Node.js 22 или новее.

```sh
npm install
npm run dev
```

Для локального API аккаунтов задай `DATABASE_URL` для PostgreSQL и выполни `npm start` после `npm run build`.

## Android APK

```sh
npm install
npm run android:add
npm run android:sync
npm run android:open
```

В Android Studio выбери **Build → Build Bundle(s) / APK(s) → Build APK(s)**. Для входа в аккаунт укажи URL опубликованного сайта в `auth-config.js` перед сборкой APK.

## Музыка

Демо-треки в проект не встроены. Можно добавить собственные аудиофайлы; они воспроизводятся в текущем браузере. Кнопка «Микс» перемешивает загруженные треки. Тексты песен добавляются пользователем и сохраняются в браузере.
